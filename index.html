What am I looking at?

The arithmetic mean of five calibrated CSSDM predictions, using Planet imagery, WorldClim and AlphaEarth features. These are model prediction scores, not validated occupancy probabilities.

All 3,123 model species are included. 66 counties have predictions; Monroe has no source imagery and is shown as unavailable. Prediction cells are on the original approximately 504 m projected grid.

Web values are quantized for fast loading. The maximum rounding error is shown for each species. Float32 scientific outputs are unchanged and retained separately. No spatial downsampling is applied to stored web values.

Enhanced colors use statewide percentiles, not county-specific normalization. Color clipping does not change the value shown when you click a cell. Zoomed-out pixels may represent multiple grid cells; click to inspect the original grid value.

This atlas supports qualitative ecological review; it is not an independent model-performance evaluation. 2023 imagery does not make this a validated 2023 occupancy map.

No login or analytics. The optional OpenStreetMap basemap requests tiles from its provider.
